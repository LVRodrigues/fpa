A Análise de Pontos de Função (Function Point Analysis - FPA) é uma técnica de medição de software que quantifica a funcionalidade fornecida ao usuário final com base em uma especificação de requisitos. Ela é usada para estimar o tamanho, esforço e custo do desenvolvimento de software. Aqui está uma visão geral do método:

Passos da Análise de Pontos de Função

  • Identificação das Fronteiras do Sistema
    • Defina as fronteiras do sistema a ser medido. A fronteira separa o sistema do ambiente externo.
  • Contagem das Funções de Dados:
    • Arquivos Lógicos Internos (ALI): Conjuntos de dados ou informações que são mantidos dentro do sistema.
    • Arquivos de Interface Externa (AIE) Conjuntos de dados ou informações que são mantidos fora do sistema, mas são usados pelo sistema.
  • Contagem das Funções Transacionais:
    • Entradas Externas (EE) Processos que recebem dados ou informações do usuário.
    • Saídas Externas (SE): Processos que enviam dados ou informações ao usuário.
    • Consultas Externas (CE): Processos que envolvem a consulta de dados ou informações pelo usuário.
  • Atribuição de Pesos às Funções
    • Cada tipo de função (ALI, AIE, EE, SE, CE) recebe um peso baseado na complexidade (Baixa, Média, Alta).
  • Cálculo dos Pontos de Função Não Ajustados (PFNA)
    • Multiplique a quantidade de cada tipo de função pelo seu respectivo peso e some os resultados.
  • Ajuste dos Pontos de Função
    • Aplique fatores de ajuste baseados em características gerais do sistema, como desempenho, segurança, etc. Isso resulta nos Pontos de Função Ajustados (PFA).
